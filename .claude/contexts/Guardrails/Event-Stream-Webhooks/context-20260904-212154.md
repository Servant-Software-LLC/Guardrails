BLOCKERS/NOTES:

- **General pattern reconfirmed this session**: partition parallel subagents by file
  ownership to avoid lock contention (e.g., #564 alone; #596+#597 together since both
  touch `RunCommand.cs`; #566+#603 together since both touch CI/`Program.cs`/
  `LogServer.cs`), tell each lane NOT to run solution-wide tests, then have the lead run
  solution-wide verification personally after rebasing everything onto a clean branch —
  this is what caught the #596 reflection-arity regression that no individual lane could
  have seen.
- **Timing-sensitive test anti-pattern** (now fixed in this codebase, worth applying
  elsewhere): never assert wall-clock elapsed time in a test; expose the internal
  DECISION a component made (an internal test-observable property) and assert that
  instead. Elapsed-time assertions conflate "wrong behavior" with "the CI runner was
  busy" and are a recurring source of flakes.
- **Release/CI parity trap is a recurring class of bug** in this repo specifically —
  ci.yml gets fixed, release.yml quietly doesn't, and it has cost a released version
  before (see user memory `skipped-tests-are-invisible-evidence-loss`). Worth checking
  this pairing explicitly before every future tag/release, not just this once.
