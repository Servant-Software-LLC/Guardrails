  load-bearing practice. Keep doing it with an agent that did not author the thing.**
- **THE `samples verify` CONTRACT — this halted the first run.** `guardrails samples verify` passes the
  sample as argv[0] AND `GR_SUBJECT`, **absolute**. A sampled guardrail must (a) honour `GR_SUBJECT`
  and (b) NOT `Join-Path` it to the workspace. Extra cases are named `X.invalid-<qualifier>.cs` —
  qualifier AFTER the token; `X.<qualifier>.invalid.cs` is an orphan. **Author-time smoke testing by
  staging samples into real target paths does NOT exercise any of this — run `guardrails samples
  verify` before declaring a folder ready.** Filed as #559.
- **`--no-merge-on-success` + deliver via PR is the right shape** for "CI green AND merged": the run
  leaves work on `guardrails/<plan>`, you push, PR, let CI gate it, merge. Read to the END of the
  output — the `*** WORK NOT DELIVERED ***` banner comes after the green summary.
