--- Maintainer rulings worth not re-litigating ---
- **`costly` is TRI-STATE** (overrules the DoR's "absent = false"). Three states in the SCHEMA, TWO at
  the predicate: `ServesTier` is `Costly is not true`, so absent AND explicit-false both serve — an
  un-annotated registry must stay routable. The third state is what lets `providers init` find the
  NOT STATED ones and ask; "absent = false" made that unaskable.
- **A comment a human DELETED must not come back.** The skip is keyed on "the key exists", not "a comment
  is near it" — stickiness is structural, no marker written into the user's file.
- **Hand-code Stage 1.5 + workstream B** (not through Guardrails): enumeration means network calls and a
  flaky guardrail erodes trust in a whole run.
- **Difficulty maps to a candidate SET, not to strength**: tier tag → blocks whose `routing.tiers`
  contains that rung → ordered by ASCENDING strength → first wins. A `hard` task gets the WEAKEST model
  the operator declared capable of hard. NO numeric tier→strength mapping, and a hard task whose only
  capable blocks are costly fails validate (GR2048), never escalates.
