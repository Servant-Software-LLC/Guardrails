  **only** `IPromptRunner` in the tree. Every tier — easy, medium, hard — resolves to a Claude model,
  because there is nowhere else to route. Routing across Haiku/Sonnet/Opus is real saving and Stage 3
  makes it legible; **"route easy work to the local box" is not reachable until #223 ships**, and #223 is
  gated on a real local endpoint existing to test against. Do not read the three green stages as
  delivering the local-inference thesis — the charter says this in a `:::warn` and it is still true.
- **THE DOMINANT DEFECT CLASS, measured again all session.** #508 (a halt announcing INCOMPLETE over a
  gate that recorded PASS), #512 (a gate printing PASS after rejecting), #516 (a classifier reading
  content instead of the failure). Every one is a mechanism reporting health it never verified.
  [[silent-failure-is-the-recurring-defect]].
- **READING DOES NOT FIND THESE. EXECUTION DOES.** Wave 1's four BLOCKERs came from running mutations,
  none from two full read passes. Wave 5's clean review was backed by **93 executed mutation cases**.
  Budget for execution in every review.
- **#510 is the gap this stage kept proving:** nothing ever executes a committed sample pair, so
  guardrail-quality proof is 100% prompt and 0% gate. Every probe run this session was run BY HAND.
- **Cost, measured across the whole stage: ~$145 for Stage 3.** A breakdown is **~$10 regardless of plan
  size** (the composed prompt is 283 KB, almost all inlined skill). Do NOT trim the inlined skill to save
  money without measuring what a trimmed skill produces.
- **A wave must be sized to what ONE breakdown can author.** That was a 30-minute ceiling; #504 raised it
  to a 20-minute SILENCE bound with a 4h cap, so the binding constraint is now the agent's own turn
  budget, not the clock. Wave 5 took 38+ minutes and would have died three times over under v1.9.0.
- **`git tag` and `git push origin <tag>` must be SEPARATE Bash calls** — chaining them with `&&` trips
  the auto-mode classifier, and that denial is about the compound command, not about permission to
  publish. [[tagging-a-guardrails-release]].
