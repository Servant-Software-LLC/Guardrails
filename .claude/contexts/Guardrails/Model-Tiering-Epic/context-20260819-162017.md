BLOCKERS/NOTES:
- **#464 IS THE MACOS GATE.** `WorktreeContainmentHook` compares paths by pure string
  normalisation; on macOS `$TMPDIR` is `/var/folders/…` which is really `/private/var/folders/…`. If
  the two sides get spelled differently the hook **blocks legitimate in-worktree writes** — every
  write, every task — and its tests structurally cannot see it. Fix it BEFORE a MacBook dogfood or a
  release intended for one. Do NOT reintroduce `realpath` (GNU-only; cost 13 macOS failures) — bake
  in both spellings.
- **LOCAL INFERENCE IS NOT NEEDED, and is not available.** `local` / `openrouter` / `codex` /
  `openai-compat` are RESERVED wire tokens with no concrete runner (`PromptRunnerRegistry` throws
  `InvalidOperationException` naming the kind); only `claude` constructs a real runner, everything
  else is deferred to #223. Dogfooding needs the `claude` CLI, same as on Windows. What the MacBook
  actually needs is a published release.
- **#482 CORRECTED — the retry budget is PER-RUN, not lifetime.** `budget` is a local recomputed on
  entry and `attemptIndex` is a plain counter starting at 1, never seeded from the journal. A
  cancelled attempt does NOT consume budget; a resume gets a fresh one. My original claim was wrong
  and the `retries:` edits it caused were unnecessary (harmless). What IS real: attempts-made and
  budget-remaining are different numbers and nothing surfaces the second.
- **THE DOMINANT AUTHORING DEFECT: guardrails that constrain the SHAPE of correct code.** Three
  fired in one live run, two more were caught pre-emptively only because the first prompted an audit
  for the same pattern. Every one was written *while fixing a different defect in the same file*.
  Spellings seen: a statement-bounded proximity window (`[^;]{0,200}`); a literal `MarkupLine`
  required in a method body; a C# type name demanded of a document that names zero record types.
  **The test before writing any token probe: can a correct implementation be written that this
  rejects?**
