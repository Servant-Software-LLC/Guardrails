### The two risks I went in expecting, and how the wave had already closed them

**The deletion (task 03) must assert the folder is GONE, not that something changed.** It does, and it
goes two steps further than the brief asked. It backs the directory-absent clause with a recursive FILE
COUNT (a `Remove-Item -Recurse` over a tree with one locked file leaves a residue that still looks like a
plan), and it carries two **over-delete** guards asserting that
`docs/plans/pilot-seat-model-provenance.md` — a sibling path PREFIX, which a trailing wildcard would take
— and `docs/plans/model-tiering-stage-3`, *this plan's own folder*, both still exist. Its own comment
makes the sharp point: neither loss would fail a build or a test, and the harness's `writeScope` check
reports an over-delete as a scope violation **without naming what was lost**. Choosing a SCRIPT action
here rather than a prompt is also right — one deterministic filesystem operation with an exactly known
target has no judgement in it to spend a model on.

**The models-used line is a classic hollow-assertion target (#73)** — a summary that green-lights an
empty list. Closed in the behaviour names themselves:
`RenderedLine_NamesEveryRecordedModel_WithAStrictlyPositiveCount`,
`AttemptsWithoutAModel_AreExcluded_WithNoBucketOfTheirOwn`, and
`RunWithNoRecordedModel_SummarizesAndRendersNull` — the genuinely-empty case rendered as null rather than
as a fake positive.

### Considered and deliberately NOT flagged

**Task 01 authors two test classes plus a stub (3 paths, `maxTurns: 100`).** Wave 3's equivalent was
split, and the mechanical reflex is to split this one too. It should not be: wave 3's task fed **three
independent consumers**, so splitting unlocked real parallelism and cut a 12-behaviour all-or-nothing
census into 5/4/3. Here there is **one** consumer — task 02 makes both classes green — so a split would
add tasks and unlock nothing, while the retry it protects against is bounded at 7 behaviours across two
files. It is also under GR2042's threshold and `validate` is silent. Applying wave 3's remedy here would
be cargo-culting the fix rather than the reasoning.
