   both read plausibly and both were already satisfied.
2. **Two-sided smoke test** (#302). Each script guardrail was executed against a hand-synthesized
   **valid** and **invalid** workspace. A guardrail is only credited when valid ⇒ 0 **and** invalid ⇒ 1.
   15 cases, all PASS.

finding in the pass and one neither executed probe would have reached.
